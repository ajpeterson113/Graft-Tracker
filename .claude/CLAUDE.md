# Graft-Tracker repo

The web view pages here (README.md, Patients.md, tracker/*.md, patients/*.md, view/home*.png and the tab bar in Prospects.md) are generated by `tools/site/build_site.py`. After every tracker update, run it as described in tools/site/README.md and commit the result, so the home page always shows the latest numbers (AJ 11/5: never skip it; if the Patients db export is refused, pass Chi West's data/patients.json). Never hand-edit those pages; change the script instead.

The patient list Excel (Chi_West_Patient_List.xlsx) is built by `tools/patient_list.py` from a fresh export of the Chi West Patients db (usage in its docstring). Refresh the Good Samaritan "To Order" block with `--to-order` (next week's Good Sam visits against the WCC shelf count), or pass `--prev Chi_West_Patient_List.xlsx` to carry the current block over unchanged.

Case sheets made from sticker photos are built with `tools/case_sheet.py` (spec format in its docstring; blank form in tools/case_sheet_template.png). Crop the sticker from AJ's photo, keep initials only, and write the case-sheets/<initials>-<mmdd>.md page alongside the .jpg/.pdf it produces. On AJ's own case sheet photos, never write on the photo: when the PO comes in, put it in the top banner with `tools/case_sheet.py --banner` ("PO <number>   |   Application N"), which also replaces an older banner.
