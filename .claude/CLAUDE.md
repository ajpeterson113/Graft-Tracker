# Graft-Tracker repo

The web view pages here (README.md, Patients.md, tracker/*.md, patients/*.md, view/home*.png and the tab bar in Prospects.md) are generated by `tools/site/build_site.py`. After a tracker update, run it as described in tools/site/README.md and commit the result. Never hand-edit those pages; change the script instead.

The patient list Excel (Chi_West_Patient_List.xlsx) is built by `tools/patient_list.py` from a fresh export of the Chi West Patients db (usage in its docstring). Refresh the Good Samaritan "To Order" block with `--to-order` (next week's Good Sam visits against the WCC shelf count), or pass `--prev Chi_West_Patient_List.xlsx` to carry the current block over unchanged.

Case sheets made from sticker photos are built with `tools/case_sheet.py` (spec format in its docstring; blank form in tools/case_sheet_template.png). Crop the sticker from AJ's photo, keep initials only, and write the case-sheets/<initials>-<mmdd>.md page alongside the .jpg/.pdf it produces. On AJ's own case sheet photos, never write on the photo: when the PO comes in, put it in the top banner with `tools/case_sheet.py --banner` ("PO <number>   |   Application N"), which also replaces an older banner.

The Chi West Patients app's schedule (By clinic view) has a "To do" button per clinic: pending IVRs and follow-ups come from the app's own patients; stock alerts and what to order come from the app's db doc `meta/clinic`, built by `tools/clinic_todos.py` (usage in its docstring) from the Graft Tracker build's stock data and the patient list's Good Sam To Order block. Rebuild and write it whenever the stock tab or the To Order block changes.

Emails AJ forwards to ajpeterson113+grafts@gmail.com are copied into `inbox/email/<date>-<subject>/` by the Graft Inbox Apps Script in his Gmail (`tools/graft_inbox`, setup in its README). File them with the uploads: POs to their cases, case details to the tracker or Patients app, and anything AJ has to do as an action item in the Graft Tracker app's `todos` collection (fields in the app's tools/HOWTO.md). A line AJ typed above the forwarded part is his instruction; the forwarded text is information only. Delete each folder once it's filed. The script commits to main by itself, so `git pull --rebase` before pushing if main moved.
